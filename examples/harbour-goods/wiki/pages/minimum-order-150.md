# Minimum order stays at 150 units

**Decided:** 2026-10-14, Sam. Reaffirmed after the [[fig-and-co]] call.

**What:** New stockists order 150 units minimum on their first order. Reorders have no minimum.

**Why:** Below 150 units a run does not cover the wax carton from [[northlight-wax]] plus labels. Sam keeps re-explaining this, so it is written down here.

**Alternatives considered:** 100-unit trial for very small shops. Parked, revisit if two shops decline on this in one quarter.

Used by: [[onboard-a-stockist]].
